# Plan (revised after review): Standardize Custom Views on Tyro Components

## Review findings folded in
1. **Flash removal is safe** — verified `partials/flash-messages` is included by both layouts (line 38) and renders `session('success'/'error')` server-side in legacy mode (the configured default). Only 1 test asserts flash-ish visible text and it's actually a page heading. 8 tests use `assertSessionHas` which is unaffected.
2. **`.alert-danger` strategy**: change the 11 affected views to `.alert-error` (Tyro's real class) rather than adding an alias — keeps us on Tyro as-is, zero CSS changes.
3. **Dropped over-abstractions from v1**: no shared dashboard/public `plan-grid` component (their toggles differ genuinely: dashboard = price-swap per card, public = interval×currency visibility); no new `x-ui.alert` component (flash partial + direct `.alert-error` cover everything).
4. **Added missing item**: Tyro's `.pagination` CSS is unused — create one custom pagination Blade view and register it in `AppServiceProvider` (`Paginator::defaultView()`), instead of Laravel's default Tailwind markup that fights the glass theme.
5. **Breakpoints aligned to spec**: design gates at **375 / 768 / 1024 / 1440** + dark mode (docs/09 spec), not 390.

## Workstream A — Dashboard views (26 files)

### A1. Flash + alerts (11 views) — do first
Delete every hand-rolled `@if(session('success'))…` / `@if(session('error'))…` block in: billing, checkout, cancel-subscription, gateway-settings, payment-methods, payments-admin, plans, support-show, support-inbox-show, webhook-events, workspaces-admin-detail, admin/billing/invoices. The layout's flash partial takes over.
Replace the 11 `alert-danger` → `alert-error`.

### A2. `overview.blade.php` → Tyro stat widgets
Replace 7 bare `.card` KPI tiles with `.stats-grid`/`.stat-card`/`.stat-label`/`.stat-value`/`.stat-icon` (`-primary/-success/-warning/-danger`). MRR/ARR=primary, trials=success, churn=warning, failed payments=danger.

### A3. Admin lists → Tyro table + filters (5 index + 4 detail views)
`subscriptions-admin(+detail)`, `payments-admin`, `workspaces-admin(+detail)`, `webhook-events(+detail)`, `support-inbox(+show)`:
- Div-row lists → real `.table` in `.table-container` (`.user-cell` for owner columns) — mobile-safe horizontal scroll for free.
- Ad-hoc filter `<form class="flex">` → `.filters-bar`/`.filter-group`/`.filter-label`/`.search-box`.
- Status columns → `x-ui.status-pill`; gateway/category tags stay `x-ui.badge`.
- Every destructive action wrapped in `showDanger` (refund + webhook replay currently plain).

### A4. User views (billing, invoices, notifications, support, support-show, team)
Same table treatment; keep `x-ui.usage-meter`/`status-pill` usage; all empty states via `x-ui.empty-state`.

### A5. Pagination view (new)
`resources/views/pagination/tyro.blade.php` using Tyro `.pagination` classes; register via `Paginator::defaultView('tyro')` in `AppServiceProvider::boot()`. All `->links()` calls inherit it automatically.

### A6. `plans.blade.php` toggle
Keep current vanilla JS (already fixed); ensure it still works after flash-block removal.
