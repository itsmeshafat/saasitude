# Install project skills into ZCode

## Context

`.zcode/skills/` already mirrors `.agents/skills/` (41 skills — most are real copies, 5 are pointer files to `.agents/skills/`, which is a supported pattern). The only skill not yet installed is **devops-engineer**, which exists only in `.commandcode/skills/devops-engineer/` (untracked in git).

## Steps

1. Copy `.commandcode/skills/devops-engineer/` → `.zcode/skills/devops-engineer/` (contains SKILL.md + references/).
2. Read its SKILL.md and flag anything suspicious per AGENTS.md third-party skill safety rules.
3. Record it in `docs/skills-lock.md` (project convention: pinned skill versions).
4. Verify with `ls .zcode/skills/` that all 42 skills resolve.

Note: the new skill will be picked up on the next session start (skills are listed at session init).
