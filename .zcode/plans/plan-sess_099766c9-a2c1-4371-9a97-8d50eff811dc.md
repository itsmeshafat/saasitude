# Plan: Fix Dashboard Styling Root Cause + Design-System Compliance + Chart Layout

## Context — the decisive finding

**Tailwind CSS is never loaded in the Tyro dashboard layouts** (`layouts/admin.blade.php` and `layouts/user.blade.php` load only Tyro's hand-written CSS + fonts — zero `@vite` references). Consequences:

- **Every `x-ui.*` component (all Tailwind-based: button, badge, status-pill, empty-state, plan-card) renders unstyled in dashboards** — this is the real "most buttons are not styled to our design system".
- **All chart layouts are inert**: the bars chart's 12 flex bars stack vertically and pour down the card, grid rows (`xl:grid-cols-3`, `xl:col-span-2`) do nothing, `w-full` SVGs render fixed-width, label rows collapse — this is "graphs misplaced, not aligned".
- The earlier standards work (stat-cards, tables, filters) looked fine only because those use Tyro's own CSS classes.

Secondary chart defects (even once Tailwind loads): line-chart per-point labels can't align with inset points; donut+legend stack left; no inset chart panel (Tyro frames its charts with a bordered muted box); `.stats-grid` auto-fit wraps 4th card to an orphan row; `stat-change` missing on some cards creates uneven heights; stat icons are text glyphs in 44px boxes.

---

## Workstream A — Load Tailwind in dashboard layouts (root cause)

Add `@vite('resources/css/app.css')` + `@stack('scripts')` wiring to the published `layouts/admin.blade.php` and `layouts/user.blade.php` (in `<head>`, after Tyro's styles so tokens apply). Then sweep for preflight fallout (Tailwind resets heading margins, list styles, border colors) against Tyro's own pages — `.page-title`, `.card-title` etc. set explicit styles; fix any drift found in the gate.

## Workstream B — Chart components rebuilt to Tyro's aligned pattern

- **All three charts**: wrap SVG in an **inset panel** (`border: 1px solid var(--border); border-radius: 10px; padding: 1rem; background: var(--muted)`) — Tyro's frame pattern that makes charts look contained.
- **line**: `width="100%" height={h}` attributes + `display:block`; labels reduced to **first/last range labels** (Tyro's pattern — never per-point); keep `preserveAspectRatio="none"` with stroke-width 2.5 (matches Tyro).
- **donut**: `grid-template-columns: 140px 1fr; align-items: center` — donut centered in its column, legend rows `justify-between` (label left, pct right), plus a Total footer.
- **bars**: grid `repeat(12, 1fr)` with value caption + bar + label **in the same cell** (can't misalign).
- **Overview stat cards**: replace `.stats-grid` auto-fit with explicit `grid grid-cols-2 md:grid-cols-4` (no orphan wrap); render `stat-change` on every card (`—` when null); replace text-glyph icons with inline SVGs (Tyro's pattern); drop the double `.stat-label` sub-captions that cause uneven bottoms.

## Workstream C — Kit fixes (from prior approved plan, unchanged)

- `x-ui.button`: add `href` + `full` props (kills 13 anchor-wraps + 9 raw `.btn`); `sm` → `h-9`.
- `x-ui.input`: render Tyro's `.form-input` class internally (glass styling), keep label/error/hint.
- New `x-ui.select` (same API, `.form-select` + chevron).
- Published styles: `.filters-bar { width: 100% }`, define `.form-radio { accent-color: var(--primary) }`.

## Workstream D — Pages (prior plan's W1–W4, unchanged in substance)

- Plans page controls → segmented `x-ui.button` controls; checkout → `x-ui.button full` + `x-ui.input` coupon + utilities instead of inline styles; success/cancel hard-coded oklch → `color-mix(in oklab, var(--success) 12%, transparent)`.
- Unwrap all anchor-wrapped buttons; convert raw `.btn` usages; Export CSV inline `margin-left:auto` → `ml-auto`.
- All forms → `x-ui.input`/`x-ui.select`/`.form-radio` with error props; `text-align:right` → `text-right` (~19 cells); `font-weight` inline hacks → classes.
- Grids `xl:grid-cols-*` → `md:grid-cols-*` (13 usages — matches Tyro `.grid-2` tablet behavior).
